How to use:
1. Put background.png inside assets/images/
2. Put all member image files inside assets/images/
3. Open index.html locally to test.
4. For deployment, upload the whole folder structure exactly as-is.
5. Current meeting editing uses browser localStorage.
6. When backend/database is ready, replace localStorage save/load with API calls.
